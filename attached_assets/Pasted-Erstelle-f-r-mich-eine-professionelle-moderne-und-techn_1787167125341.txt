Ich möchte das komplette Projekt später als **ZIP-Datei herunterladen** und auf **Render.com als Web Service deployen**.

Deshalb muss das Projekt Render-kompatibel sein.

Erstelle:

* funktionierende `package.json`
* Build Script
* Start Script
* Production Build
* Server soll den gebauten Frontend-Ordner ausliefern
* PORT muss über `process.env.PORT` funktionieren
* Render-kompatible Serverkonfiguration
* keine hardcodierten localhost URLs in Production
* `.env.example`
* `.gitignore`
* README.md mit Deployment-Anleitung

Beispiel:

Build:
`npm install && npm run build`

Start:
`npm start`

Der Node-Server soll sowohl API als auch Frontend bedienen.

# Abschlussanforderung an Replit

Baue nicht nur ein visuelles Mockup.

Erstelle das vollständige funktionsfähige Projekt.

Nach Fertigstellung:

1. überprüfe alle Seiten und Routes,
2. behebe TypeScript-Fehler,
3. behebe Build-Fehler,
4. überprüfe Mobile Responsive,
5. teste die Formulare,
6. teste den Production Build,
7. teste `npm start`,
8. stelle sicher, dass das Projekt Render-kompatibel ist,
9. prüfe alle internen Links,
10. entferne unnötigen Demo-Code,
11. entferne ungenutzte Komponenten,
12. erstelle eine saubere README,
13. hinterlasse das Projekt in einem Zustand, in dem es vollständig als ZIP exportiert und anschließend auf Render deployed werden kann.

**Priorität: Qualität vor Geschwindigkeit.**

Die Website soll aussehen und technisch aufgebaut sein wie eine professionelle Unternehmenswebsite, die für Hausverwaltungen, Gewerbekunden, Bauträger und Privatkunden gleichermaßen vertrauenswürdig wirkt.
